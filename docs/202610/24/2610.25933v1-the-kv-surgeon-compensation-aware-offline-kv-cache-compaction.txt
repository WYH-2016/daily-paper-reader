# ABSTRACT 

Offline compaction of the key–value cache (KV-cache) reduces the cost of repeat-edly querying a fixed context by constructing a smaller cache once and reusing it subsequently. The central challenge of compaction is deciding which cache entries to delete and which to retain. Existing methods score each candidate for deletion on its own, with the rest of the cache being held fixed. However, softmax renor-malization of the attention operation couples these decisions in a nonlinear man-ner: removing one entry changes the attention weights of every remaining one. In this work, we introduce KV-S URGEON , which uses calibration data to take inter-actions into account in a tractable way. We derive a quadratic surrogate that admits closed-form expressions for jointly making the optimal greedy removal decision as well as compensation within the remaining entries. On QuALITY, LongHealth, and Long Code Arena, and at every evaluated compaction ratio, KV-S URGEON 

substantially advances the cost–accuracy Pareto frontier of dense and mixture-of-experts models from 4B to 30B parameters. At 50 × compaction, KV-S URGEON 

improves question-answering accuracy by up to four points over attention match-ing (Zweiger et al., 2026), the state of the art, at comparable cost. Lastly, we introduce an even faster variant, which also exceeds the state of the art while re-quiring only two fifths of its cost. 

# 1 INTRODUCTION 

Many large language model (LLM) applications repeatedly query a fixed context such as a docu-ment, patient record, or codebase. The key–value cache (KV-cache) for such a context grows linearly with its length and occupies a large fraction of the memory used during long-context inference. Ev-ery attention layer reads this cache for every generated token, so every request pays for its size in both memory and latency. Offline compaction reduces this cost by processing the context once and compressing the resulting cache, which is then used to serve all later requests (Eyuboglu et al., 2026; Kim et al., 2026; Zweiger et al., 2026). Unlike serving-time eviction, which discards cache entries within the forward pass of a request (Zhang et al., 2023; Li et al., 2024), offline compaction can spend a larger one-time budget that is amortized over future requests. In particular, it can use calibration queries , i.e., query vectors the model produces while re-reading or discussing the context, to decide which entries to retain. Eyuboglu et al. (2026) introduce this regime with Cartridges , which trains a new latent cache per context. More recent work makes offline compaction much cheaper by replacing end-to-end training with eviction-inspired selection and efficient optimization of the remaining cache (Zweiger et al., 2026). The central problem in cache compaction is deciding which cache entries can be removed while preserving the resulting attention outputs. The effect of one deletion therefore depends on which other entries remain, mak-ing selection a combinatorial problem rather than a ranking problem. Scores based only on received attention, as in attention matching (Zweiger et al., 2026), additionally overlook value redundancy: if an entry’s value is close to the output the head already produces, i.e., ∥vj − o∥22 is small, removing it might change the output little, even when its attention weight is large. Good selection must therefore account not only for the contribution of each entry, but also for how deletions interact. Recent output-aware methods instead estimate the output error caused by deleting a single entry (Goel et al., 2026; An et al., 2026; Gu et al., 2026; Feng et al., 2026). CAOTE (Goel et al., 2026) de-rives the exact change caused by deleting one entry for a single calibration query, and OBCache (Gu et al., 2026) uses a Taylor approximation of the attention output error aggregated across queries. These methods nevertheless evaluate the deletion of one entry while the rest of the cache is held fixed. Attention matching (Zweiger et al., 2026) refits the retained cache to minimize the error of the compacted output, but only after the retained set has been chosen. What is missing is compensation-aware selection : each candidate deletion should be scored by the error remaining after the surviving entries have been adjusted to compensate for it, so that selection and refitting are optimized jointly 

rather than in sequence. This is difficult under softmax attention because deletion changes the nor-malization itself, so the error after both deletion and compensation has no obvious closed form. In this work, we substantially advance the cost–accuracy Pareto frontier for offline KV-cache com-paction. We derive a quadratic surrogate that makes compensation-aware selection tractable. We introduce KV-S URGEON , which uses this surrogate for greedy, compensation-aware elimination. For each candidate deletion, the surrogate admits closed-form expressions for both the optimal com-pensating update and the resulting increase in surrogate loss. Each candidate entry is assigned a score after the remaining entries have been adjusted to compensate for its removal, and the update is then applied to the cache, so the next deletion is chosen against the compensated entries, as Optimal Brain Surgeon (OBS) (Hassibi & Stork, 1993) does for network weights. # 2 RELATED WORK 

Other forms of KV-cache compression. KV-caches can be compressed along several axes. Quan-tization lowers the precision of stored keys and values (Liu et al., 2024; Hooper et al., 2024), and low-rank methods reduce the feature dimension (Saxena et al., 2024; Chang et al., 2025). Both are complementary to reducing the number of entries. A different route, LLM summarization , shortens the text input itself by prompting an LLM to summarize it. This approach transfers across models, but gives no direct control over cache size. We study compaction along the sequence dimension, where a fixed budget of entries is retained from an already computed cache. 

Offline compaction. Offline methods exploit contexts that are processed once and queried repeat-edly. Cartridges (Eyuboglu et al., 2026) trains a new latent cache per context from self-generated data. KVzip (Kim et al., 2026) removes cache entries based on the attention they receive while the model repeats the context verbatim. Attention matching (Zweiger et al., 2026) also keeps a subset of the original keys, then fits a scalar logit bias per retained key and refits the stored values to re-produce the original attention outputs on reference queries. Its AM-HAK variant selects entries by root-mean-square attention, and AM-OMP, based on orthogonal matching pursuit (OMP), greedily selects keys so that their reweighted attention reproduces the attention mass of the full cache. In both, the support is chosen from attention statistics before the values are refit, so the ability of the retained entries to reproduce the output does not influence selection. 

Eviction by proxy scores. Serving-time eviction discards entries within a single request, ranking each one by a score that ignores the rest of the cache: accumulated attention, as in H2O (Zhang et al., 2023) and related methods (Oren et al., 2024; Li et al., 2024; Liu et al., 2023), or a query-free proxy such as position (Xiao et al., 2024), key norm (Devoto et al., 2024), alignment with a principal query direction (Godey et al., 2025), deviation from neighboring keys (Liang et al., 2025), or value norm (Guo et al., 2024). Merging methods soften the same decision by folding evicted entries into retained ones. KVMerger (Wang et al., 2024) merges similar entries into attention-weighted pivots, and Zhang et al. (2024); Wan et al. (2024); Nawrot et al. (2024) use related rules. In all of these, the score of an entry is fixed before any other entry is removed. 

Output-aware eviction. More recent methods score entries directly through the attention-output error induced by their removal (Goel et al., 2026; An et al., 2026; Gu et al., 2026; Feng et al., 2026). CAOTE (Goel et al., 2026) and ReST-KV (An et al., 2026) derive the exact effect of deleting one entry for one query. OBCache (Gu et al., 2026) derives a second-order approximation in the style

CriticalKV (Feng et al., 2026) considers deletion of an arbitrary set for one query and derives an additive upper bound on the resulting output error for selection. These methods differ in how they estimate deletion error, but share a common restriction: candidates are evaluated with the retained cache held fixed. Our work starts from the same output-reconstruction objective as CAOTE, ReST-KV, and OBCache but changes how it is used for selection. Instead of scoring one deletion against a fixed cache, we derive a quadratic surrogate of the output error over arbitrary deletions and reweightings of the retained entries, aggregated over many calibration queries, and let the retained entries compensate during greedy deletion of cache entries.

# 4 EXPERIMENTS 

We compare KV-S URGEON to existing methods and show that it improves the cost–accuracy fron-tier across different models, benchmarks, and compaction ratios. We then analyze which part of the algorithm is the source of this improvement through controlled ablations. Finally, we study how much of the gain is retained when self-study calibration is replaced by a single repeat pass. Our code is available at github.com/ZIB-IOL/KV-Surgeon. 4.1 EXPERIMENTAL SETUP 

Benchmarks and models. We evaluate offline KV-cache compaction on long-context multiple-choice question-answering tasks from QuALITY (Pang et al., 2022) and LongHealth (Adams et al., 2024), and code completion tasks from Long Code Arena (Bogomolov et al., 2024), where each compacted context is reused across many questions. We evaluate five models, Qwen3-4B, Qwen3-4B-Instruct-2507, Llama-3.1-8B-Instruct, Gemma-3-12B, and Qwen3-30B-A3B (Yang et al., 2025; Grattafiori et al., 2024; Team et al., 2025), spanning three model families, dense and mixture-of-experts architectures, and different attention variants. The gain over independent selection comes from compensating the surviving cache entries as the support changes. To isolate this effect, we keep the surrogate, candidate pool, calibration queries, and final refit fixed and disable only the compensating update: we delete entries based on the saliency (11) but do not apply the update (12) to the remaining entries, so the saliencies stay fixed and the elimination reduces to a single ranking of the candidate pool. At 50 × compaction on Qwen3-4B with QuALITY, this reduces accuracy from 66 .9% to 63 .9% (Table 2). KV-S URGEON without com-pensation also performs similarly to LOO, which uses the different deletion rule (13) and does not adapt the remaining entries at all. Replacing the saliency score alone does not explain the improve-ment. Rather, the gain comes from updating the remaining entries during selection. Additional controls that remove the opportunity for iterative compensation lead to the same conclusion (Ap-pendices E and F). The improvement is also not an artifact of the optimized allocation of the global cache budget across heads inherited from Zweiger et al. (2026). Under uniform allocation, KV-S URGEON remains 3.0

accuracy points ahead of AM-HAK (Appendix E). Compensation-aware support selection therefore provides an improvement that is orthogonal to that of the offline-compaction pipeline proposed by Zweiger et al. (2026). 4.4 CHEAP CALIBRATION PRESERVES MOST OF THE GAIN 

KV-S URGEON is comparatively insensitive to how calibration queries are collected. Replacing self-study with a single repeat pass reduces pipeline time from 145 to 54 seconds per context at 50 ×

compaction while reducing mean accuracy by only 1.2 points. The same change is substantially more costly for AM-HAK, which loses 4.9 points (Table 1). This makes KV-S URGEON -fast not only cheaper, but sufficient to outperform all prior methods at the primary operating point. This robustness persists across compaction ratios. # 5 CONCLUSION 

Prior offline KV-cache compaction methods first deleted cache entries and then adapted the remain-ing ones. We showed that deletion and adaptation can be coupled efficiently, and that doing so improves accuracy. We derived a quadratic surrogate of the attention-output error that allows for an efficient greedy algorithm with compensation-aware selection: every candidate deletion is scored af-ter the retained entries have compensated for it. The resulting method, KV-S URGEON , improves the cost–accuracy frontier at every compaction ratio on QuALITY, LongHealth, and Long Code Arena with models from 4B to 30B parameters, and its fast variant exceeds all prior methods at two fifths of the cost of the strongest baseline. A controlled comparison attributes the gain over independent selection to compensation during selection, not to the surrogate.

# B ALGORITHM AND IMPLEMENTATION 

Algorithm 1 in Section 3.4 gives the complete procedure for one attention head. This section pro-vides the hyperparameters, solvers, and computational details. 

Multipliers as logit biases. For every retained entry j ∈ S, the compacted cache stores the original key kj , the refit value bvj , and the logarithm log wj of its multiplier. At inference, log wj is added to the logit of entry j before the softmax, so that the entry contributes eZij +log wj = wj eZij to the unnormalized attention of query i, which is (2). The bound e−β ≤ wj ≤ eβ of the final refit is the bound |log wj | ≤ β on the logit bias of any single entry; it bounds the shift that compaction introduces and leaves the original logit Zij unchanged. Mass preservation, μi ≈ 1, keeps the total unnormalized attention of the compacted cache at that of the original cache, so that the compacted cache draws the same share of attention when it is served next to other tokens (Appendix H).

# C EXPERIMENTAL DETAILS 

This section records what is needed to reproduce and read the experiments; Section 4.1 gives the summary. Appendix C.1 states the protocol and conventions and Appendix C.2 breaks down where the pipeline time goes. C.1 PROTOCOL AND CONVENTIONS 

Task and benchmarks. The model reads a context once, the resulting cache is compacted once by a target factor between 5× and 100 ×, and all benchmark questions about that context are answered from the compacted cache, so calibration and compaction are one-time costs per context. QuALITY uses the dev split, articles 0–49, with n = 894 multiple-choice questions; one article is one con-text. LongHealth consists of 20 fictional patient records, grouped into four contexts of five patients with roughly 60k tokens each; each record is compacted as its own chunk at the same ratio and the compacted chunks are concatenated (Appendix H), and all n = 400 multiple-choice questions are evaluated against their contexts. Accuracy is the percentage of correctly answered questions. Answers are extracted from the generated text, and questions whose answer cannot be parsed count as incorrect; parse rates are checked per run and are uniformly high in the reported cells, so parsing does not drive the reported differences. All eight model and benchmark combinations are reported. 

Compaction ratio and per-head budgets. The compaction factor, 5× to 100 ×, is the nominal ratio of the original cache size to the compacted one. Cache-side methods are reported at the nominal ratio because measured effective ratios agree with it to within one percent. Heads differ widely in how much compaction they tolerate, so the compaction factor is a global budget rather than a per-head prescription. Head (ℓ, h ) receives its own retained fraction rℓh , subject to the constraint that mean ℓh rℓh equals the reciprocal of the compaction factor; each head is additionally capped at 

rℓh ≤ 0.75 , and the budget a capped head cannot use is redistributed to the other heads in proportion to their shares, so the global ratio is preserved. The allocation is computed once per model on contexts disjoint from the benchmark contexts, following the procedure introduced by Zweiger et al. (2026). We measure per head how the log-perplexity of model-generated reference answers degrades as that head alone is compressed, and we allocate the budget along these influence curves. The solver is ratio-agnostic: it finds one set of per-head proportions that works across all target ratios, and this single allocation is rescaled to each compaction factor. Every method in a table consumes the same allocation, so differences between rows are attributable to selection and refit alone; the published configuration of KVzip, reported only in Table 16, is the deliberate exception. Uniform per-head budgets serve as an ablation (Appendix E). 21 Preprint. Under review. 

Calibration tiers. All implemented methods score positions against calibration queries recorded from the model itself and, except AM-OMP, come in two tiers that differ mainly in how these queries are generated. The fast tier prompts the model to reproduce the context and records the query vectors of that single pass. The self-study tier additionally generates self-study conversations about the context, which cost more time but match the future workload better. AM-HAK-fast and KV-SURGEON -fast are the fast variants of AM-HAK and KV-S URGEON . AM-OMP, AM-OMP-CS, and KV-S URGEON are self-study methods; AM-OMP-CS is the cheap-solver setting of Zweiger et al. (2026), named AM-OMP-fast there, which selects several keys per greedy step and refits less often. After selecting which positions to keep, every calibrated method applies the same support-fixed refit of the retained multipliers and values (Section 3.4), so accuracy differences between them reflect the selection rule. AM-OMP is evaluated only at the most aggressive ratios because its runtime grows steeply with the retention budget. 

Calibration queries. Self-study generates five conversations per context with vLLM: a verbatim repetition of the context, a summary, an aggregation of key facts, a JSON structuring of the context, and three self-written questions with answers. The repetition is teacher-forced, with the context itself as the answer; the summary, aggregation, and JSON conversations are answered without thinking (at most 2048 tokens, temperature 0.7, top-p 0.8, top-k 20 ); the question conversation uses thinking for both writing and answering the questions (at most 8192 and 4096 tokens, temperature 0.6, top-p

0.95 , top-k 20 ). The calibration queries are the query vectors of the answer tokens, capped at 50 ,000 

per attention head by random subsampling. The repeat pass is the repetition conversation alone, that is, a single forward pass over the context, the repeat prompt, and a second copy of the context, without any generation. Queries are extracted on-policy, following Zweiger et al. (2026): layer 0 is compacted with the original queries, and for each later layer the same sequences are run through the model with the already compacted earlier layers in place, so every layer is compacted against the queries it receives at inference. 

Replication and uncertainty. Each cell is the mean over five replicate runs with explicit seeds, and the grey number is the standard error over these runs; a single run is noisy to about ±1.5 points at n = 894 and ±2.0 at n = 400 , comparable to many method gaps, so we only trust orderings that survive the seed error bars. These standard errors measure generation noise under fixed contexts and questions, not uncertainty over the population of contexts, and LongHealth contributes only four composite contexts; generalization rests on the spread of the margins across the eight combinations in Appendix D. Full-context ceilings come from seed-replicated runs without compaction under the same protocol. 

Timing conventions. Pipeline time is the average wall-clock per context spent on calibration query generation plus compaction, in seconds. It excludes prefilling the context to extract its cache, answer generation, and answer extraction, all of which are common to all methods. Query-free methods therefore report compaction time alone. All runs are single-job SLURM runs on machines with H200 GPUs, launched with the same tooling, so times are comparable within a table; comparisons across models should be treated as indicative. Every table splits calibrated methods by calibration tier, repeat-pass above self-study; AM-OMP-CS uses self-study queries and sits in the self-study group. 

Defaults. The method defaults were fixed once on Qwen3-4B with QuALITY at 50 × and reused unchanged for every other model, benchmark, and ratio: the mass-term scale γ0 = 1 , so that γ is the RMS norm of the full-cache outputs; the ridge λ0 = 0 .01 , applied relative to the mean diagonal of P ⊤

Contexts and questions. We walk the test split in order and keep the first snapshot of each not-yet-seen repository whose Python files plus completion file fit 120 ,000 Gemma-3 tokens, until 20

A question shows the path of the completion file and its prefix, all lines before the target, in a code fence, and asks for exactly the next line; prefixes longer than 16 ,000 characters are truncated to their tail at a line boundary, which affects two questions. The prefix is part of the question, not of the compacted context, so compaction is tested through the repository context alone. The answer is generated inside an open code fence with at most 64 new tokens.

# E COMPONENT ABLATIONS 

This section holds every ablation of the shared pipeline and of KV-S URGEON behind Section 4.3 and Table 2: the shared pipeline components in Appendix E.1, compensation in Appendix E.2, and the efficiency and design choices in Appendix E.3. Every ablation runs on Qwen3-4B with QuALITY at 50 ×, changes one component of the pipeline of Section 3 at a time, and reports the mean over five seeds with one standard error over seeds. Two protocols are used and must not be mixed. The 50 -article protocol (Tables 13 and 15) is that of the main tables, 894 questions; its self-study controls are the KV-S URGEON , LOO, and AM-HAK entries of Table 1, and its time is pipeline time, calibration-query generation plus compaction. The 25 -article protocol (Table 14) uses the first 25 articles, so its accuracies are compared only against the reference row of the same panel and never against the main-table numbers, and its time is compaction only, because query generation is identical across arms. The fast-tier row of Table 13 was run with the fast configuration in use at the time of the ablation, whose reference values ( 65 .5% , 5.4 s) differ from the KV-S URGEON -fast entry of Table 1; it too is read only against its own control. Defaults are those of Appendix C. E.1 SHARED PIPELINE COMPONENTS : HEAD BUDGETS AND FINAL REFIT 

Both components are inherited from attention matching (Zweiger et al., 2026) and applied to every calibrated method, so their effect is measured per method. Table 15 switches them independently for our methods and the attention-matching baselines; the ported eviction methods are walked through the same switches in Table 16. 

Head budgets. The ablation replaces the optimized per-head budgets of Appendix C by uniform per-layer budgets at the same global ratio. It is the largest single lever, and it is not specific to KV-S URGEON : with the refit in place, KV-S URGEON loses 6.6 points, AM-HAK 6.9, and LOO 

7.8. Under uniform budgets KV-S URGEON remains 2.4 points ahead of LOO and 3.0 ahead of AM-HAK, so the selection-rule margins of Section 4.3 do not depend on the optimized budgets. KVzip, the one baseline that sets its own head allocation from a global attention threshold, leads to the same conclusion: ported with the shared budgets and refit, it collapses under strong compaction, a median of 15 .3 points below KV-S URGEON -fast at 50 × and 100 ×, yet sits a median of 1.6 points below the ceiling at 5× (Appendix D); the deficit tracks how hard the compaction is, not how good the score is. 

Final refit. The refit is ablated on the LOO support, where it can be switched off without touching selection (Table 13). Serving the selected keys with their original multipliers and values, which is plain eviction on the score of (13), costs 5.4 points against LOO with the refit. Across methods the two switches compound: the budgets are the larger lever, worth +4 to +8 points on top of the refit, and the refit adds +1 to +7 on top of raw compaction (Tables 15 and 16). The improvements are not the same for all methods, but KV-S URGEON is ahead in all three settings. Panel (c) of Table 14 decomposes the refit into its two solves on the KV-S URGEON support; it is kept as supporting evidence for Appendix H.1 and is not built on elsewhere. E.2 KV-S URGEON -SPECIFIC COMPONENT : COMPENSATION 

Panel (b) of Table 14 isolates compensation. The surrogate, the 4t candidate pool, and the final refit are held fixed and only the compensating update of (12) is disabled, so that elimination proceeds greedily on the same surrogate saliencies. This costs 2.9 ± 0.8 points (seed-paired; 3.0 between the seed means of Table 2), and leaves greedy elimination no better than LOO selection on the same articles ( 64 .7% ). Two controls show that the gain is not a better standalone objective. Shrinking the candidate pool to the support itself (pool factor 1 in panel (a)), which leaves the elimination nothing to eliminate or compensate, costs the same 2.9 points. The remaining choices change accuracy by at most one standard error at their defaults and mainly control cost. 

Mass term. Setting γ0 = 0 removes the mass term from the surrogate (Table 13). Accuracy moves by +0 .2 points, within one standard error, at 2 s more pipeline time. 

Candidate pool. The elimination runs on the min {T, ⌈4t⌉} best entries per head by the score of (13) (panel (a) of Table 14). Widening the pool to the full cache changes accuracy by 0.2 points (66 .9 against 66 .7) and multiplies compaction time by 3.8 (10 against 38 s); halving it to 2t costs

Mild-compaction fallback. # F COMPENSATION AT THE LOSS LEVEL AND CALIBRATION ROBUSTNESS 

This section measures compensation directly on the attention-output loss rather than through ac-curacy, and then asks why repeat-pass calibration costs KV-S URGEON less than it costs the exact single-deletion score; Sections 4.3 and 4.4 cite the results. All measurements use Qwen3-4B and Llama-3.1-8B, five QuALITY articles, and every head, that is, 1440 head–article pairs on Qwen3-4B and 1280 on Llama-3.1-8B. Scores are computed from the self-study calibration queries, and the exact loss of (4) is evaluated on held-out benchmark questions the scores never saw; where the same measurement on the calibration queries differs, it is given in parentheses. 

Compensation moves the support toward the oracle and generalizes. Against an oracle that runs the same greedy backward elimination but scores every candidate deletion by the exact loss (4) after refitting the remaining entries, on the 546 heads where this is affordable ( t ≤ 57 , Qwen3-4B), LOO selection sits 46% above the oracle’s loss and KV-S URGEON 25% (median relative loss 0.213 ,

0.183 , and 0.146 ; random selection 0.243 ), closing 45% of the gap, and on the typical head the closed fraction is 39% ; the oracle is itself greedy, so these gaps are to exact-loss greedy elimination rather than to the optimal support. KV-S URGEON beats LOO on 84% of heads and still shares only 

44% of its keys with the oracle set, because many near-equivalent supports exist. On the supports KV-S URGEON selects at 50 ×, the final refit leaves 25% of the raw-eviction loss on Qwen and 7.5% 

on Llama on held-out questions, against 25% and 7.7% on the calibration queries: no head overfits, and on no head is the stored cache worse than eviction. On Llama raw eviction at 50 × leaves a loss larger than the output itself, so the final refit, which every calibrated method shares, removes most of the loss there, and selection decides the remainder. The coefficients the elimination itself produces already achieve most of this ( 31% and 8% ), but they cannot be served raw: on 1% of Qwen heads and 5% of Llama heads they exceed the eviction loss, and the final refit never does, which is the loss-level counterpart of the final-refit ablation of Appendix E.1. 

Why repeat-pass calibration costs KV-S URGEON less than the exact score. Averaged over the eight combinations at 50 ×, replacing self-study queries with a single repeat pass costs KV-SURGEON 1.2 points (Table 1); the drop is 4.3 points on LongHealth with Gemma-3-12B and at most 1.3 elsewhere. At the level of rankings, recomputing the scores from a single repeat pass drops the Spearman correlation between the surrogate and the exact loss over random deletion sets, computed within one head and one set size, from 0.905 to 0.786 on Qwen and from 0.929 to 0.833 

on Llama, and that of the score of (13) from 0.881 to 0.690 on both, so under cheap queries the surrogate loses about half the ranking fidelity the exact score loses. Cross-head comparability, which is what the per-head budget allocation consumes, is unaffected ( 0.81 and 0.91 at 98% deletion), so budget allocation does not need self-study queries. The surrogate is therefore less sensitive to the calibration queries than the exact score, not insensitive. 

Hypothesis, not tested as a mechanism. The factor (1 − Pij )−2 in the exact deletion score amplifies exactly the queries a repeat pass gets wrong: a query for which one token receives unusually large attention contributes disproportionately to that token’s score, so an atypical repeat-pass attention pattern moves the exact ranking more than it moves the frozen surrogate, which contains no such amplification. This is consistent with the measurements above and is a candidate mechanism for the fast-tier robustness of Section 4.4, but it does not establish why AM-HAK degrades more strongly under the same change: AM-HAK ranks tokens by attention mass rather than by either of these objectives, so its larger calibration drop may have a different cause. 33 Preprint. H.1 THE ROLE AND LIMITS OF MASS MATCHING 

Attention matching (Zweiger et al., 2026), the strongest prior offline method, builds its selection and refit around reproducing each query’s attention mass on the compacted block. Two consequences of Section 3.2 matter here: for how the refit must be run, and for what mass matching can tell selection. 

Per-position mass fitting is harmful alone and misleading as a selection signal. Non-uniform multipliers change the retained attention pattern, so the original values no longer reconstruct oi

under the reweighted pattern. Fitting multipliers to mass targets without the subsequent value solve is therefore worse than no refit at all, which is why the refit of Section 3.4 applies the two solves only as an ordered unit. This is measured on the KV-S URGEON support: re-solving the multipliers alone scores 12 .0 points below serving the elimination’s own coefficients with no refit at all, and 

14 .2 below the full final refit (panel (c) of Table 14). The mechanism is the reweighting rather than the mass objective in particular, so the ablation bounds what mass fitting costs when it is run alone and does not separate it from other multiplier objectives. Mass matching also misleads selection. Weighting the mass term heavily, formally γ → ∞ in (9), reduces the saliency (11) to its mass component, so that entries are ranked by their contribution to reproducing the attention mass alone, as in attention matching, and their values play no role in selection. This discards both factors that the exact loss (13) says matter, the value novelty ∥vj − oi∥2 and the heavy-hitter weight (1 − Pij )−2.At mild compaction the difference is small, because retained masses stay near one and all criteria agree. At aggressive compaction the two criteria part ways, and the exact loss sides with the output: replacing mass ranking by KV-S URGEON selection inside an otherwise identical pipeline is worth 

1.3 points at 20 ×, 3.0 at 50 ×, and 4.3 at 100 × (Figure 2). None of this contradicts the published attention-matching results, because all of those results com-bine mass matching with a value refit.
