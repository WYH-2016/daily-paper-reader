## 摘要
本工作提出了qGAMMA——一种灵活的框架，用于探索与优化混合精度深度神经网络（DNN）模型在支持多种定点与浮点精度的通用型空间加速器上的映射。qGAMMA借助领域专用遗传算法及基于硬件综合结果的解析性能模型，在设计空间中进行高效搜索，从而确定可最小化目标指标（如延迟、能耗或资源占用）的最优映射方案与加速器配置。在多种DNN工作负载上的广泛评估表明，qGAMMA为混合精度应用的设计提供了重要洞见，有助于在性能、能效与资源利用率之间实现更优的权衡。

## Abstract
This work describes qGAMMA, a flexible framework for exploring and optimizing the mapping of mixed-precision Deep Neural Network (DNN) models onto general-purpose spatial accelerators that support a range of fixed- and floating-point precisions. qGAMMA navigates the design space using a domain-specific genetic algorithm and an analytical performance model based on hardware synthesis results. The framework identifies the optimal mapping and accelerator configuration that minimizes target metrics. Extensive evaluations across DNN workloads show that qGAMMA offers valuable insights for designing mixed-precision applications, enabling better trade-offs between performance, energy efficiency, and resource utilization.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：在支持**多精度硬件模块**（如 FP32/FP16/FP8/INT8/INT4 等并存）的现代 AI 加速器上，如何为**混合精度 DNN 模型**（即不同层使用不同精度）自动寻找最优的**软硬协同映射方案**（dataflow + 精度分配 + 并行结构 + 存储层次配置），以同时优化延迟、能效与资源利用率。
- **研究动机**：
  - 现有映射框架（如 Timeloop、GAMMA、LOMA）均假设**单精度执行**，无法建模“每层精度可变”与“硬件多精度流水线并存”的双重复杂性；
  - 多精度加速器（如 NVIDIA Hopper、IBM/NVIDIA 7nm AI 芯片）已商用，但缺乏系统级自动化设计空间探索工具；
  - 混合精度模型（如 HAWQv3 生成的 INT8/INT4 ResNet18）带来显著能效增益，但其映射需联合优化精度选择与数据流，否则易出现跨层配置冲突（如 INT4 层最优 cluster 配置导致 INT8 层性能退化）。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：将混合精度 DNN 映射建模为一个**高维、约束耦合的组合优化问题**，通过**领域定制遗传算法（GA）+ 硬件合成驱动解析模型**实现高效搜索。
  
- **关键技术细节**：
  - **三层基因组编码（3-level genome）**：
    - L3-mapper：PE 集群间数据流（跨 Cluster 并行）；
    - L2-mapper：PE 集群内数据流（跨 PE 并行）；
    - L1-mapper：**新增**——用于建模低精度 MAC 的细粒度并行（如 INT8 → 4-way SIMD on 32-bit lane），强制限制 `K`（输出通道）维度的空间映射以避免累加混淆；
    - FP32/INT32 使用原 GAMMA 的 2-level 编码；低精度自动触发 3-level 扩展。
  - **增强型数据流模型**：显式将每层权重/激活精度作为输入参数，驱动功能单元建模（如 multiplier count = 32/Q）、累加器位宽、缓冲区 packing 方式等。
  - **启发式剪枝（3 条关键 heuristic）**：
    - H1：PE 数量限制为 2 的幂（除 inner cluster 由精度决定）；
    - H2：按数据流维度大小降序优先并行化（外层选 top-3，中层选 top-2，内层固定 K 受限）；
    - H3：`K` 和 `C`（输入通道）维度 tile size 仅取 2 的幂（符合实际 DNN 层结构惯例）。
  - **性能估计工具**：
    - 基于 MAESTRO 改造，新增**多精度活动能耗模型**：区分 FP/INT pipeline stage 数、packed memory access energy、NoC 数据包格式开销；

## 6. 主要结论与发现

- qGAMMA 是**首个支持混合精度 DNN 到多精度加速器端到端自动映射的框架**；
- 引入 **3-level genome + precision-aware dataflow** 可精确建模低精度 SIMD 行为，避免累加错误；
- 启发式剪枝使搜索效率提升 **31–51%**，且不牺牲最终解质量（latency 仅改善 4%，但收敛速度翻倍）；
- 在 uniform 精度下：FP8 相比 FP32 提升 EDP **21.4×**，INT4 相比 INT16 降低 energy **3.03×**，验证多精度潜力；
- 在混合精度下：相比 uniform INT8，qGAMMA 实现 **1.20× latency speedup** 与 **17% energy reduction**，证实跨层精度协同优化价值；
- 单一 clustering 约束下，qGAMMA 倾向选择**低精度层（INT4）的配置作为全局最优**，但可能导致高精度层（INT8）次优——揭示混合精度映射中的**固有张力**。
