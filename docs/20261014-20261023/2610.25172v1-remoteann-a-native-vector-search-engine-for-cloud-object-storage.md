## 摘要
构建在云对象存储之上的向量搜索引擎正日益受到学术界与工业界的共同关注。此类系统通常采用存算分离架构，将主要向量数据持久化存储于对象存储（例如 Amazon S3）中，而仅在计算节点上保留紧凑的索引元数据。然而，传统向量索引结构并未原生适配云对象存储所固有的高网络延迟与按请求计费的访问开销，从而导致网络 I/O 放大、查询吞吐量下降以及更高的 API 费用。为应对上述挑战，我们提出 RemoteANN——一种在索引构建与查询处理两方面均针对云对象存储协同设计的向量搜索引擎。为缓解主导性的网络 I/O 瓶颈，RemoteANN 将倒排文件（IVF）索引与 RaBitQ 量化方法相结合，并通过簇间与簇内数据重排序进一步优化，以提升数据局部性。基于该定制化的数据布局，RemoteANN 的查询引擎融合了簇剪枝、细粒度 Range-GET 请求、请求合并以及本地 NVMe SSD 缓存机制，在不牺牲精度的前提下显著减少了离散存储请求次数与网络传输数据量。为解决索引构建瓶颈，我们进一步提出了 QGKMeans 方法，在不损害聚类质量的前提下大幅降低索引构建延迟。在真实世界数据集上的大量实验表明：相较于代表性基线方法，RemoteANN 在达到 97% 目标召回率时，查询吞吐量最高可提升 5.9 倍，同时对象存储请求次数最多可减少 16.1 倍。

## Abstract
Vector search engines built on cloud object storage have drawn growing attention from both academia and industry. These systems typically adopt a disaggregated storage-compute architecture, persisting the primary vector payload in object stores (e.g., Amazon S3) while retaining compact index metadata on compute nodes. However, conventional vector indexing structures are not natively tailored to the pronounced network latency and per-request access costs of cloud object stores, resulting in network I/O amplification, degraded query throughput, and higher API expenses.   To resolve these challenges, we present RemoteANN, a vector search engine explicitly co-designed for cloud object storage across indexing and querying. To mitigate the dominant network I/O bottleneck, RemoteANN couples an Inverted File (IVF) index with RaBitQ quantization, further optimized by inter-cluster and intra-cluster data reordering for improved data locality. Building on this tailored data layout, RemoteANN's query engine combines cluster pruning, fine-grained Range-GET requests, request merging, and local NVMe SSD caching, dramatically reducing discrete storage requests and network transfer volume without sacrificing accuracy. To address the index construction bottleneck, we further develop QGKMeans, which substantially reduces construction latency without compromising clustering quality. Extensive evaluations on real-world datasets demonstrate that, compared with representative baselines, RemoteANN achieves up to a $5.9\times$ throughput speedup while issuing up to $16.1\times$ fewer object storage requests at 97% target recall.
