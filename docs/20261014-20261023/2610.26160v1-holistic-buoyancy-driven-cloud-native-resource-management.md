## 摘要
在多租户云环境中，高效资源管理面临挑战，因为各类工作负载竞争共享资源（如末级缓存和内存带宽），而这些资源的拥塞程度会随工作负载构成与资源需求的动态变化而实时改变。现有资源管理方法通常依赖静态资源需求假设或预先进行的工作负载性能分析，难以及时响应云环境中动态变化的资源争用状况。本文利用“工作负载浮力”（workload buoyancy）——一种在运行时捕获工作负载对各单项资源及应用层性能敏感性的框架——实现自适应调度与资源管理。我们提出一种全局性方法，将浮力指标融入工作负载调度、节点本地资源分配以及工作负载全生命周期内的重调度过程。我们将该方法实现为一个原生支持 Kubernetes 的原型系统，并在多节点集群上、针对多种典型云工作负载及不同强度的资源争用场景开展评估。在高拥塞场景下，相较于 Kubernetes 基线方案，本方法使满足服务等级目标（SLO）的工作负载占比平均从 7.74% 提升至 87.8%，同时降低了资源拥塞程度、SLO 违反的严重程度以及集群碎片化水平，且仅需有限次数的重调度。

## Abstract
Efficient resource management is a challenge in multi-tenant cloud environments as workloads compete for shared resources such as last-level cache and memory bandwidth, whose congestion can change dynamically as workload composition and resource demands evolve. Existing resource management approaches often rely on static resource requirements or prior workload profiling, limiting their ability to respond to changing resource contention as required in the cloud. In this paper, we leverage workload buoyancy, a runtime framework for capturing workload sensitivity to individual resources and application-level performance, to enable adaptive scheduling and resource management. We propose a holistic approach that incorporates buoyancy into workload scheduling, node-local resource allocation, and workload rescheduling throughout the workload lifecycle. We implement our approach as a Kubernetes-native prototype and evaluate it on a multi-node cluster using diverse cloud workloads under varying levels of resource contention. In a high-congestion scenario, our approach increases the percentage of workloads satisfying their SLOs from 7.74% to 87.8% on average compared with the Kubernetes baseline, while reducing resource congestion, the severity of SLO violations, and cluster fragmentation using limited rescheduling.
