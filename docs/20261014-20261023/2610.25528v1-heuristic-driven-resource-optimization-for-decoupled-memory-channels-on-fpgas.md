## 摘要
在高层次综合（HLS）中，为解耦访存-执行（DAE）架构确定OpenCL通道深度，对平衡性能与硬件效率至关重要。传统的静态分析工具通常过度配置这些内存通道以确保性能安全，从而导致大量硬件资源闲置。本文扩展了一种基于LLVM的静态分析框架（该框架最初用于自动化生成DAE），引入了一个硬件感知的精化层。我们发现了一种反直觉的“性能反转悖论”，其与基线内存停顿相关：对于高停顿率的网格型内核，其峰值性能反而出现在极小的通道深度处；若增大通道深度，吞吐量最多可能下降61%。为此，我们提出一种启发式精化层，利用基线停顿与性能饱和之间的相关性来优化OpenCL通道深度。实验结果表明，所扩展的框架能够成功识别各类基准测试中的“最小峰值性能点”。通过规避标准过度配置所引发的性能陷阱，我们在典型HotSpot应用中实现了2.52倍的资源效率提升。该方法在维持峰值执行加速比的同时，确保了最精简的硬件资源配置，优于保守的基于工具的静态预测。

## Abstract
Determining OpenCL channel depths for Decoupled Access-Execute (DAE) architectures in High-Level Synthesis (HLS) is critical for balancing performance and hardware efficiency. Conventional static analysis tools often over-provision these memory channels to ensure performance safety, leading to significant resource stranding. This paper presents an expansion of an LLVM-based static analysis framework, originally proposed for automated DAE generation, by introducing a hardware-aware refinement layer. We identify a counter-intuitive Performance Inversion Paradox linked to baseline memory stalls, where high-stall, grid-based kernels reach peak performance at minimal channel depths and suffer up to a 61% throughput degradation when depths are increased. We propose a Heuristic Refinement Layer that optimizes OpenCL channel depths based on this correlation between baseline stalls and performance saturation. Experimental results demonstrate that our expanded framework successfully identifies the Minimal Peak Performance point across various benchmarks. By avoiding the performance traps of standard over-provisioning, we achieve a 2.52x improvement in Resource Efficiency for an illustrative HotSpot application. This approach maintains peak execution speedup while ensuring the leanest possible hardware profile, outperforming conservative tool-based static predictions.
