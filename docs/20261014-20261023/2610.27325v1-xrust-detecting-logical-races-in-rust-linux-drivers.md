## 摘要
Rust 日益被用于 Linux 以提升内存安全性，但其保障机制无法防止逻辑竞态：即使各操作本身均经过同步，它们仍可能以破坏高层不变性的顺序交错执行。检测此类缺陷通常需人工编写的规范及严格受控的执行环境。本文提出 XRust——一种无需人工指定不变式即可检测 Linux 中 Rust 驱动程序逻辑竞态的技术。XRust 基于逻辑先行发生（Logical Happens-Before, LHB）分析，识别与逻辑顺序相关的共享状态访问，自动构建操作对测试桩（harness），并利用串行差分预言器（serial differential oracles）检测违背任一串行顺序的并发执行行为。此外，XRust 还采用轻量级用户空间抽象，在可重现的调度下执行驱动代码。在 Linux 7.3-rc2 上的应用结果表明，XRust 从十个驱动程序的 102 个 Rust 源文件中识别出 17 个共享对象，构建了 1654 个可执行测试桩，并发现了两个此前未知的逻辑竞态。其中 rnull 块设备驱动的竞态已被 Linux 维护者确认，相关修复补丁已合入 Linux 块子系统代码树。

## Abstract
Rust is increasingly used in Linux to improve memory safety, but its guarantees do not prevent logical races: individually synchronized operations can still interleave in ways that violate higher-level invariants. Detecting such bugs typically requires manually written specifications and carefully controlled execution environments.   We present XRust, a technique for detecting logical races in Linux Rust drivers without manually specified invariants. Using Logical Happens-Before (LHB) analysis, XRust identifies shared-state accesses relevant to logical ordering, automatically constructs operation-pair harnesses, and uses serial differential oracles to detect concurrent executions inconsistent with either serial order. XRust also uses lightweight userspace abstractions to execute driver code under reproducible schedules. Applied to Linux 7.3-rc2, XRust identifies 17 shared objects across 102 Rust files from ten drivers, constructs 1,654 executable harnesses, and discovers two previously unknown logical races. The rnull block-driver race has been confirmed by Linux maintainers, with a fix accepted into the Linux block subsystem tree.
